# 2026-11-13 影瞳 CineEye

## 任务
用监督学习做「图片/视频帧 → 电影类别」识别，搭建开发框架并实现主要代码。

## 硬件与选型结论
- 本机：Intel Core Ultra 5 125H（18 逻辑核）、30GiB 内存、646GiB 可用；仅 Intel Arc 核显，
  无 /dev/dri、无 nvidia-smi → CUDA/MPS/XPU 全部不可用，**只能 CPU 训练**。
- 选型：**PyTorch（CPU 版 2.9.1+cpu / torchvision 0.24.1+cpu）为主框架**，
  scikit-learn 仅作 HOG+颜色直方图基线标尺。
- CPU 路线固定为 `model.mode=feature`：冻结 ImageNet 预训练主干 → 一次性缓存深度特征 → 只训轻量分类头；
  `finetune` 端到端模式可用但纯 CPU 很慢。

## 本机环境坑（已写进代码/requirements）
- `/tmp` 与 `/dev/shm` 都只有 10MB：pip 装大包会 ENOSPC，`cineeye/__init__.py` 自动把 TMPDIR 指向项目 `.tmp`；
  `dataset.py::_safe_num_workers` 检测 shm <256MB 时强制 `num_workers=0`（否则 DataLoader Bus error）。
- OpenCV 5 移除了 `cv2.HOGDescriptor`：`requirements.txt` 锁定 `opencv-python-headless>=4.9,<5`，
  `classical.py` 增加纯 NumPy HOG 后备实现。
- 官方 PyPI/PyTorch 源约 30kB/s：改用阿里 PyPI 镜像 + `mirrors.aliyun.com/pytorch-wheels/cpu`。
- 预置 `resnet18-f37072fd.pth` 到 `.cache/torch/hub/checkpoints/`，`__init__.py` 检测到本地 .pth 时设置 TORCH_HOME，离线可训练。
